# obstacle_stop 뒤 승인된 차선변경 곡선의 전방 이동

## 복원 기준

최신 `delayed-shift-replan-20260910`의 직진 길이/새 저속 곡선 탐색을 제거하고,
`selfcar-2026-vtd:no-signal-proximity-20260910`
(`0b358c26008d85441367469b62d78d24623705f9242f22fd32a842a547af0223`)의
차선변경 패키지 소스로 먼저 복원했다. 교차로 통과 판단 이후의 충돌 재검사와
신호등 근접만으로 차선변경 요청을 차단하던 조건의 해제는 유지된다.

변경 전 최신 소스, Dockerfile, 문서, 이미지 정보와 현재 상황은
`/home/a/autoware-task-backups/translate-approved-curve-20260910.v67ozmy8`에 보존했다.

## 새 동작

승인 후 실행 중이며 기존 정지 기준을 충족한 차량에 실제
`/planning/planning_factors/obstacle_stop`의 STOP이 있을 때 재계획한다.
메시지 수신 시간과 메시지 stamp가 모두 기존 timeout(기본 0.5초) 안에 있어야 한다.
STOP 위치/속도 조건은 기존 obstacle_stop 수신기의 기준을 사용한다.
로컬 충돌 검사나 장애물 거리만으로는 승인된 곡선을 새로 만들지 않는다.

최초 재계획 시 승인된 곡선을 원본으로 보관한다. 현재 차선 중심선의 진행 방향으로
1 m부터 12 m까지 1 m 간격으로 평행이동한다. 이미 지나온 부분은 제외하고, 자차를
원본 경로에 투영한 위치 이후 첫 원본 점부터 남은 곡선의 모든 위치에 동일한 XY
변위를 더한다. 남은 곡선의 방향, 점 간 거리와 길이는 그대로 유지한다. 원본에서의 총 이동량을
제한하므로 정지가 반복되어도 계속 멀리 밀리는 동작은 없다.

현재 정지 자세에서 옮긴 곡선 시작점까지의 접근 구간만 보간한다. 이미 원본 곡선에
진입한 경우에도 차량을 원본 시작 위치로 되돌리지 않는다. 이동시킨 시작점이 현재
차량 뒤에 있거나 연결 구간이 조향 한계를 넘으면 해당 후보를 거부한다.

속도 상한은 기존 정지 재계획 속도(현재 1.5 m/s), 상위 경로 속도, 원본 곡선의 최소
속도 중 가장 작은 값이다. 각 이동 거리에서 그 속도의 100%, 75%, 50%를 검사한다.
상위 속도 0 또는 원본 곡선의 정지점을 덮어쓰지 않는다. 목표 차선/RTC 승인 상태는
유지하며, 남은 곡선을 압축하거나 다시 맞춰 만드는 fallback은 없다.

남은 원본 곡선이 40 m보다 길어도 그대로 보존하므로 이전 재생성 방식의 40 m 상한을
적용하지 않는다. 이동 후 끝점은 현재/목표 차선 끝 및 기존 규제 구간 이전이어야 한다.

## 경로 검사와 상태

- 연결 구간과 원본 곡선의 조향 한계, 활성화된 횡가속/횡저크 제한을 검사한다.
- 이동 후 차선 소속을 다시 계산하고 차량 footprint 전체가 합법적 차선 연결 안에
  있는지 검사한다. 목표점도 승인된 목표 차선 안에 있어야 한다.
- 곡선 뒤의 기존 연장 구간도 동일하게 이동한다. 연장 구간이 도로 밖으로 나가면
  합법적인 부분까지만 남기고 끝점 속도를 0으로 한다. 차선변경 완료 후 제동 거리와
  stop margin이 확보되지 않는 짧은 연장 구간은 기존 정적 안전 검사에서 거부한다.
- 차선변경 금지 경계, 정적 장애물, 후방 추월 차량, 동적 예측/RSS 검사를 유지한다.
  시간 예측이 차선변경 끝까지 도달하지 못하면 거부한다.
- 안전한 후보만 교체하며 실패하면 기존 경로와 정지를 유지한다. 1초 재시도 간격과
  50 ms 후보 사이 시간 예산을 사용한다. 다음 후보 인덱스만 이어서 사용하고 안전
  판정은 현재 자세/객체로 다시 한다. 한 후보 검사 시간만큼 예산을 넘을 수 있다.

정지 입력의 구독은 일반/회피/외부 요청 차선변경에서 공통으로 사용한다. 기존 자동
RTC 강제 승인 기능의 enabled 설정과 대상 모듈 조건은 별도로 유지한다.

## 빌드

`docker/vtd/translated-curve.Dockerfile`은 복원 기준 이미지를 기반으로 일반 차선변경,
회피 차선변경, 외부 요청 차선변경 패키지를 함께 빌드한다. `NormalLaneChange`에
원본 곡선 상태가 추가되므로 파생 플러그인도 같은 공개 헤더로 다시 빌드한다.

```bash
docker build -f docker/vtd/translated-curve.Dockerfile \
  -t selfcar-2026-vtd:translated-curve-20260910 .
```
