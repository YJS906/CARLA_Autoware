# Town05 밀집 교통 부하 진단 — 2026-09-23

차량250대·보행자500명 상태에서 실시간 처리 성능이 부족하다. 컴퓨터 전체의 메모리 고갈이나 과열은 관측되지 않았지만, CARLA 메인 스레드와 브리지 및 일부 Autoware 모듈에 계산 부하가 집중된다. 큐가 계속 길어지는 현상을 확인한 것은 아니며, 동기식 시뮬레이션 시간 자체가 느리게 진행된다.

## 측정 조건

오전10:49~10:53 KST 부근. i9-12900K(24논리CPU), RTX4060Ti16GB, RAM31GiB. CARLA0.9.16 Town05_Opt, Epic/1280×720, Autoware ground_truth 모드. fixed_delta_seconds=0.05, sync_mode=true. 기존 브리지만 tick을 소유한다. 하드웨어/world40초, ROS30초 및 추가20초 측정. 설정·객체 수·에고 모드·경로를 변경하거나 재시작하지 않았다.

## Autoware 처리와 지연

첫30초 측정에서 예측 객체261~269개가 각 메시지에 포함됐다. 객체 예측 처리 평균79.53ms/최대102.82ms, 행동 경로 계획 평균71.60ms/최대102.65ms, 행동 속도 계획 평균39.18ms/최대57.73ms. 계획 하위 모듈 시간은 상위 총시간과 중복되므로 더해서 해석하지 않는다. 예측의 평균 처리시간 자체가20Hz의50ms 간격보다 길어, 현재 객체 수로 모든 단계를 실시간20Hz로 처리할 여유가 있다고 볼 수 없다.

객체·제어 명령은 실제 시간 기준6.8~7.2Hz, 최종 /planning/trajectory는 추가20초 측정에서3.59Hz였다. 제어 명령의 최대 수신 간격은 첫 표본289ms, 추가 표본259ms였다. 동기식 시뮬레이션 시간 기준으로는 갱신이 이어지지만, 현실 시간 기준 반응 갱신은 느리다.

최신 수신 /clock 대비 객체 메시지 시각 차이는0~50ms(시뮬레이션 시간) 범위였고 증가 추세는 관측되지 않았다. 위치 추정은 첫 표본에서 최대200ms, 추가 표본에서는 최대50ms였다. 최종 궤적도 추가 표본에서0~50ms였다. 이 값은 ROS 콜백 수신 순서의 영향을 받으며, DDS 큐 길이나 센서부터 실제 차량 반응까지의 전체 지연을 직접 측정한 값이 아니다. 따라서 무제한 큐 적체를 확인하지는 못했지만, 모든 지연이 없다고도 결론 내리지 않는다.

## 별도 확인된 상태

- AI crowd 등록 실패 경고(`Vehicle agent not added to the crowd by some problem!`)가 교통 도구 로그에 반복된다. 로그는 약8.8MB였다. 정확한 실패 원인과 보행자 회피 영향은 이번 읽기 전용 진단에서 확정하지 않았다. 모든 NPC가 정상 동작한다고 단정할 수 없다.
- ROS 진단에는 pose_twist_fusion_filter/pose 미수신, gyro scale 추정 경고, 수동 조작 heartbeat/door 입력 부재가 포함됐다. 이들이 이번 교통량 증가로 새로 발생했는지는 확인하지 않았다. 실제 /localization/kinematic_state는 수신 중이었다.
- 최근 Autoware 로그에 횡단보도 제동 거리 부족 및 제어 명령 변화량 제한 메시지도 있다. 성능 저하만으로 원인을 단정하지 않으며, 이번 진단은 충돌 방지 동작 검증을 대체하지 않는다.
- 현재 실행 중 교통 도구의 nonowned.walkers 음수 표시는 이전에 확인한 통계 계산 문제다. 저장된 수정 소스는 있으나 이번 작업에서 프로세스를 재시작하지 않았다. world에서 직접 확인한 실제 수는 차량250대·보행자500명이다.

## 판단과 조정 후보

지금 밀도는 실시간 주행 검증용으로 무겁다. 주요 병목 후보는 CARLA 메인 스레드의 도시/물리/AI 처리와 브리지·객체 예측 등 CPU 경로다. 함수별 프로파일을 수행하지 않았으므로 개별 함수의 비용 분담까지 확정하지 않는다. GPU 품질만 낮춰 해결된다고 보장할 수 없다.

직전 동일PC 측정에서100대/150명은18.27Hz, 200대/350명은10.29Hz였다. 에고 위치와 계획 부하가 달라 엄밀한 대조 실험은 아니지만, 다음 조정은100대/150명부터 같은 구간을 다시 측정하는 것이 합리적이다. 이번 요청은 확인이므로250대/500명 설정을 유지했다.
