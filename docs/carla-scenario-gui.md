# Town05 시나리오 GUI

실행 중인 CARLA Town05에 차량과 보행자를 배치하는 로컬 데스크톱 편집기입니다.
바탕화면의 **CARLA 시나리오 스튜디오** 또는 다음 명령으로 엽니다.

```bash
./scripts/carla/carla_scenario_gui
```

CARLA 0.9.16 Python 환경(`/home/a/CARLA/venv-0.9.16`)과 Tkinter가 필요합니다.
다른 Python 경로는 `CARLA_PYTHON`으로 지정할 수 있습니다.
지도는 `/home/a/autoware_data/maps/Town05/lanelet2_map.osm`을 읽습니다.

1. **현재 주행 차량으로 이동**으로 현재 위치를 찾습니다. 휠로 확대하고 빈 곳을 드래그해 이동합니다.
2. **차량 추가** 또는 **보행자 추가**를 선택하고 지도를 클릭합니다. 아직 초안이며 실제 객체는 생성되지 않습니다.
3. 오른쪽에서 동작·속도·방향을 바꾸고 **객체 설정 반영**을 누릅니다. 차량은 정지 또는 차로 주행, 보행자는 대기 또는 목표까지 걷기를 지원합니다.
4. 보행자는 목록에서 선택한 뒤 **선택 보행자 도착 지점**으로 목적지를 클릭합니다. 차량 속도는 km/h, 보행자는 m/s입니다.
5. **저장/불러오기**로 JSON 시나리오를 보관하고, **시나리오 실행**으로 실제 CARLA에 배치합니다.
6. **실행 객체 정리**를 누르면 편집기가 만든 객체만 삭제합니다. 창을 닫을 때도 실행 객체를 정리하고 초안을 보관합니다.

왼쪽의 **교통량 적용**은 기존 도시 교통 컨트롤러의 목표 수를 변경합니다.
배경 차량 수에는 에고와 편집기 차량이 포함되지 않습니다. 보행자 목표는
전체 보행자 기준이므로 편집기 보행자가 추가되면 배경 보행자가 줄어들 수 있습니다.

편집기 객체의 ID·역할·종류와 CARLA world ID를 기록해 기존 차량의 삭제를
방지합니다. 일부 배치가 실패하면 그 실행에서 생성한 객체를 정리합니다.
월드 재시작, Autoware Engage, 경로 변경, 동기화 tick은 실행하지 않습니다.
에고에서 6m 이내의 객체 생성은 거절합니다.

현재 기능은 기본 객체 배치와 교통량 설정입니다. 시간/거리 트리거, 차량별
경유 경로, 끼어들기 동작, OpenSCENARIO 가져오기는 지원하지 않습니다.
보행자는 지정점까지 직선으로 걷고, 주행 차량은 Traffic Manager를 따릅니다.
이 편집기의 JSON은 OpenSCENARIO 파일이 아닙니다.

상태와 자동 저장 초안: `~/.local/state/carla_pp/scenario-gui/`.
저장된 정지 차량 시나리오: [`scenarios/gui/stop_car.json`](../scenarios/gui/stop_car.json).
불러오기 후 현재 주변 차량과 배치 위치를 확인하고 실행합니다.

검증 명령:

```bash
/home/a/CARLA/venv-0.9.16/bin/python -m unittest discover \
  -s tools/tests -p test_scenario_gui_backend.py -v
```

객체 소유권·삭제 실패 처리·부분 생성 실패 시 정리·입력 검증 등 7개 테스트를
통과했습니다. 실제 CARLA 연결과 지도 표시를 확인했고, GUI 작업 대기열과
창 닫기 시 정리는 모의 엔진으로 검사했습니다. 이 검증은 시나리오별 자율주행
성공이나 충돌 회피를 보증하는 주행 시험은 아닙니다.
