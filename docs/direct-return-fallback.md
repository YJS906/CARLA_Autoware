# 목적지 차선 직접 복귀 대안 (2026-09-10)

## 변경

기존 목표(일반적으로 한 차선씩 복귀)를 먼저 검사하고, 안전한 경로를 찾지 못하면
목적지 우선 차선까지 직접 이동하는 대안을 한 번 더 검사한다.
두 차선 떨어진 현재 상황에서는 중간 차선에 머무는 단계를 만들지 않고
두 차선 폭을 한 번에 횡이동하는 후보를 생성한다.

기존 enable_direct_multi_lane_change 설정이 켜진 NORMAL 차선변경에만 적용한다.
같은 목표 선정·경로 생성·안전 검사를 복귀 사전계획, 실제 정지 위치의 인계 검사,
인계 이후 일반 차선변경에 사용한다. 외부 요청 및 장애물 회피의 진입 목표 선택은
변경하지 않는다. 승인 후 실행 중인 경로의 목표를 임의로 바꾸지도 않는다.

## 검색·안전

- 목적지 차선으로 향하는 합법적인 routing graph의 left/right 연결만 사용한다.
  중간 연결이 끊겼거나 경로 밖 차선/교차로 영역이면 대안을 생성하지 않는다.
- 남은 도로 길이가 충분해도 기존 후보가 unsafe이면 직접 복귀 대안을 검색한다.
  기존의 '순차 차선변경 거리가 부족할 때만 직접 변경' 조건과 별도의 fallback이다.
- 일반 차선변경 실행에서는 기존 후보에 시간 예산의 40%를 우선 배정하고,
  직접 후보는 남은 예산 내에서 계산한다. 마지막 10%는 후속 검사를 위해 남긴다.
  기존 20ms 복귀 예산과 1초 검색 간격, 한 주기 한 복귀 검색 제한은 바꾸지 않는다.
- 더 짧은 예산의 복귀 사전계획에서는 한 회차에 한 목표 영역만 구성한다.
  실패한 두 차선 복귀는 다음 검색 회차에서 직접 목표부터 구성해 검사한다.
  이후 실패 시 순차/직접 우선 검색을 교대로 수행하며, 안전 판정은 매번 새로 계산한다.
  직접 복귀를 예약한 경우 실제 정지 자세에서의 인계 검사도 직접 목표를 우선 사용한다.
- 다차선 경로의 유효성 검사에 양 끝 차선뿐 아니라 실제 가로지르는 중간 차선도 넣는다.
  기존에는 바깥 경계만 설정하고 middle_lanes가 비어 있어 중간 구간이 경로 밖으로 판정됐다.
- 복귀 완료/진행도는 실제 횡이동 종료 자세가 놓인 목표 차선에서 판단한다.
  먼 후속 구간의 lanes.back() 순위를 가져와 도착한 목적지 차선을 미복귀로 보지 않는다.
  이후 교차로에서 필요한 차선 선택은 일반 경로계획의 역할로 유지한다.
- 직접 경로도 중간 차선의 객체, 실제 최대 곡률, 경로 유효성, 정적 스윕·정지 여유,
  시간 기반 충돌/RSS 검사를 거친다.
- 직접 후보가 실패하면 기존 목표 차선·폴리곤·객체 필터·디버그·속도 준비 상태를 복원한다.
  통과하면 이 상태들을 직접 경로와 함께 유지한다. 공유 매니저 파라미터는 수정하지 않는다.
- 복귀 시작 위치, 정지 여유, 조향 한계, 횡가속도/횡저크 해제 설정은 이번에 바꾸지 않는다.

이 변경은 대안 검색을 추가하는 것이며, 해당 장면의 복귀/진입 승인을 강제하지 않는다.
단계별 안전 검사에 통과한 복귀 계획만 진입 승인을 뒷받침한다.
