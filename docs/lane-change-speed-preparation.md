# 차선변경 승인 전 감속 (2026-09-09)

## 적용 범위

일반 차선변경, 외부 요청 차선변경, avoidance-by-lane-change에 적용한다.
별도의 static-obstacle-avoidance 모듈, 지도, 충돌 여유, 제동/조향 한계는 변경하지 않는다.
실행 중인 Autoware 또는 브릿지의 설정은 변경하지 않는다.

## 동작

- 생성된 후보가 현재 속도로 안전 검사를 통과하지 못하면, 같은 형상에 감속 프로파일을
  적용해 최대 3개 목표 속도를 검사한다. 실제 수신 속도/가속도에서 시작하는 예측,
  조향·횡가속도·저크, 정적 충돌, 합류 후 정지 공간, 기존 RSS 검사를 다시 통과해야 한다.
- 속도를 낮춰야 하는 기하학적 후보는 `speed_preparation_target`으로 표시한다.
  이 표시는 승인 또는 `safe=true`를 뜻하지 않는다. 실제로 점유된 횡이동 경로에는
  이 표시를 새로 부여하지 않는다.
- 해당 후보가 아직 unsafe여도 현재 차선의 출력 경로에 감속을 적용한다.
  차선변경 회피의 거리 조건은 횡이동 승인에 유지하되, 필요한 감속 준비는 그 밖에서도 요청한다.
  승인 거리는 2026-09-10에 20 m에서 35 m로 변경했다.
- 필요한 저속은 명목 최소 차선변경 속도보다 낮게 탐색할 수 있다. 실제 차량의 조향 한계를
  넘는 곡선이나 도로/충돌 검사에 실패하는 횡이동은 속도만 낮췄다는 이유로 승인하지 않는다.
- 감속 가능한 거리나 현재 차선의 감속 예측이 부족하면 원래 속도를 반환하지 않고 정지를
  요청한다. 기존 상한과 정지 지점을 올리거나 삭제하지 않는다. 이는 물리적으로 이미 늦은
  상황에서도 충돌 없이 정지할 수 있다는 보장은 아니다.
- 기존 5초 obstacle-stop 강제 승인 실험은 **unsafe인 속도 준비 후보**를 강제 승인하지 않는다.

## 위치 기준점

`speed_preparation_start_`는 감속 요청을 처음 만든 순간의 ego 위치다.
매 주기 0.2초 제어 지연을 현재 위치부터 다시 적용하여 감속이 계속 뒤로 밀리는 것을 막는다.
더 낮은 목표 속도로 새 프로파일이 필요하면 현재 상태에서 다시 만든다.
목표 차선이 바뀌거나 모듈/유효 후보가 해제되면 초기화한다.
**차선변경 시작 위치나 경로 형상을 여러 주기에 걸쳐 고정하는 기능이 아니다.**

## 검증 및 한계

네트워크를 차단한 별도 컨테이너에서 신규 기능 단위 확인 13개를 통과했다.
실제 속도 10 m/s로 unsafe인 시험 경로는 같은 형상에서 약 4.52 m/s로 감속하는
프로파일을 적용한 뒤 전체 안전 검사를 통과했다. 승인 전 현재 차선 감속,
감속 기준점, 기존 정지점 보존, 물리적 충돌 거부, 20 m 승인 분리도 확인했다.
전체 회귀시험, VTD 시나리오 주행, 실제 제어 추종 검증은 수행하지 않았다.

이는 유효한 후보의 속도 문제를 다루는 기능이다. 후보 형상 자체가 생성되지 않거나
법규·차선 연결·물리적 충돌 때문에 불가능한 상황을 강제로 통과시키지는 않는다.
