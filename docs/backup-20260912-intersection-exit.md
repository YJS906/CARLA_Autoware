# 0912 교차로 출구 수정 — 브릿지·지도 포함 백업

Git 태그: `backup-20260912-intersection-exit`.
이전 백업 `최종`(22b9efd)을 그대로 보존하고 이후 현재 작업을 함께 저장했다.

- 교차로 출구의 후방 가상 확장 제한, 현재 차선을 따른 준비 구간과 변경 시작점 탐색.
- path optimizer 경계 정지의 재계획 연결, 최종 경계 검사 유지.
- AEB 객체 제외 점군의 좌표 처리 수정.
- 브릿지 시작 시 동일 이름 CSV의 새 내용으로 RViz 표시 갱신.
- 브릿지 전체 소스와 신호 매핑, 실행 스크립트, 파라미터 및 관련 이전 변경 포함.
- 현재 사용하는 지도 4개 파일을 `maps/backup-20260912/map.tar.gz`에 압축 저장.

원본 PC의 빌드 이미지:
`selfcar-2026-vtd:intersection-exit-20260912`
(`selfcar-2026-vtd:local`도 같은 이미지).

```text
sha256:ef00a3b3baa134b4ba5eddac52e0e27abc50f1e2edbff62fb0649b21e77e88ec
```

이미지 바이너리를 Git에 넣은 것은 아니다. 다른 PC의 전체 재빌드는 이미지 ID가
달라도 정상이며, 아래 이관 가이드에서 고정 소스·base digest로 빌드한다.
이 백업 작업은 원본 PC에서 Autoware나 브릿지를 재시작하지 않았다.

최소 확인: 최신 C++ 빌드, 교차로 출구 관련 테스트 2개, 캡처된 현재 상황 재생,
지도 압축 해제 후 4개 파일 checksum 검증, 정적 재현성 검사.
현재 상황에서는 준비 5.23 m 후 변경하며 최종 경계 정지 factor 0과 1.5 m/s 출력을
확인했다. 다른 PC에서의 전체 빌드와 주행은 이 백업 과정에서 수행하지 않았다.
